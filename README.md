# درب: ثيم شاشة السيارة (أندرويد)

تطبيق Kotlin وJetpack Compose يعمل كشاشة رئيسية (Launcher) على شاشات السيارة المبنية على أندرويد.

## ما الذي يعمل

| الميزة | الحالة |
|---|---|
| أربعة أوضاع: رياضي، فاخر، كلاسيكي، اقتصادي | يغيّر الألوان والخط وشكل العداد |
| العداد (4 أشكال Canvas) | السرعة حقيقية من GPS |
| مواقيت الصلاة بطريقة أم القرى | حساب فلكي بلا إنترنت، مع العدّ التنازلي |
| الطقس | حقيقي من Open-Meteo (يحتاج إنترنت) |
| الخريطة | OpenStreetMap، ملء الشاشة أو مقسومة مع العداد، وزر لفتح تطبيق الملاحة |
| الشريط السفلي | تطبيقات حقيقية مثبّتة على الشاشة، تُضاف وتُزال من وضع التعديل |
| التخصيص | لون (8 ألوان + شريط درجات)، شكل البطاقات، شكل العداد، إخفاء البطاقات |
| حفظ الإعدادات | DataStore |

## ما هو تجريبي

- **الدورات والغيار:** لا يعطيهما GPS. تظهران في وضع المحاكاة فقط، وتظهران في الواقع عند ربط مصدر OBD-II أو CAN.
- **بطاقة السيارة** (ضغط الإطارات والوقود والمدى والعداد الكلي): قيم ثابتة مكتوبة في الكود وموسومة «بيانات تجريبية».
- **حرارة المحرك والاستهلاك:** تظهر «—» حتى يوجد مصدر بيانات.
- **درجة «الكفاءة» في العداد الاقتصادي:** تقديرية من السرعة فقط.

## التشغيل

1. افتح المجلد في Android Studio (Koala أو أحدث). سيُنشئ Gradle wrapper تلقائياً عند أول مزامنة.
2. وصّل الشاشة بـ USB أو ADB ثم Run.
3. عند أول تشغيل وافق على صلاحية الموقع.

## جعله الشاشة الرئيسية

من إعدادات الشاشة: التطبيقات ثم التطبيقات الافتراضية ثم تطبيق الشاشة الرئيسية، واختر «درب».
أو عبر ADB:

```
adb shell cmd package set-home-activity app.darb.theme/.MainActivity
```

بعض الشاشات الصينية لها إعداد خاص في قائمة المصنّع باسم «Launcher» أو «اختيار الواجهة». وأنظمة Android Automotive الأصلية لا تسمح بتبديل الشاشة الرئيسية.

## ربط بيانات السيارة

كل مصادر السرعة تُرجع `Flow<VehicleState>` في `data/VehicleData.kt`. لقراءة الدورات والغيار من OBD-II (محوّل ELM327 بلوتوث) أنشئ Flow جديداً يملأ `rpm` و`gear`، ثم مرّره في `DarbApp.kt` بدل `gpsFlow`.

## هيكل الكود

```
app/src/main/java/app/darb/theme/
├── MainActivity.kt        نقطة الدخول (ملء الشاشة، إبقاء الشاشة مضاءة)
├── data/
│   ├── Settings.kt        إعدادات الثيم (DataStore)
│   ├── PrayerTimes.kt     حساب المواقيت
│   ├── Weather.kt         الطقس
│   ├── VehicleData.kt     GPS والمحاكاة وواجهة الربط بالسيارة
│   └── Apps.kt            قائمة التطبيقات وتشغيلها
└── ui/
    ├── Palette.kt         لوحات الأوضاع الأربعة وأشكال البطاقات
    ├── Gauges.kt          العدادات الأربعة
    ├── Home.kt            الشريط العلوي والبطاقات
    ├── MapScreen.kt       الخريطة
    ├── Dock.kt            الشريط السفلي ومنتقي التطبيقات
    ├── Customize.kt       لوحة التخصيص
    └── DarbApp.kt         الجذر
```

## ملاحظات

- الموقع الاحتياطي لحساب المواقيت والطقس قبل أول تحديد GPS هو `DEFAULT_LAT` و`DEFAULT_LNG` في `VehicleData.kt`. غيّره إلى مدينتك.
- الخطوط هي خطوط النظام (condensed وserif وsans). لاستخدام الخطوط نفسها المستعملة في المعاينة (Chakra Petch وCormorant وغيرها) أضف ملفاتها إلى `res/font` وعدّل `Palette.kt`.
- بلاطات OpenStreetMap العامة لها سياسة استخدام. استبدلها بمزوّد بلاطات مناسب قبل النشر العام.
- لم يُبنَ المشروع على جهاز فيه Android SDK قبل تسليمه. إن ظهر خطأ ترجمة صغير عند أول Sync فأرسله لي وأصلحه.
